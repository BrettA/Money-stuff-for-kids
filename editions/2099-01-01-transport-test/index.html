STORY 1
IN MATT'S ARTICLE: A Test Package

A Safe Package

One computer sends a little package to another computer. It stays locked while it travels.

THE MONEY IDEA
Computers can pass a locked package.

The Traveling Test Package

Vercel keeps this test package private while GitHub checks its special fingerprint. If the fingerprint matches, the package becomes a pull request for a person to review.

Testing a Private Publishing Bridge

The worker uploads a completed ZIP with a narrowly scoped signed URL. The bridge hashes it on the server and gives GitHub a different short-lived URL that can only download that object.

THE MONEY IDEA
Short-lived credentials reduce exposure.

An End-to-End Transport Fixture

A shared publishing token authenticates the worker without revealing the GitHub PAT. Private Blob delegation URLs constrain upload, download, and deletion independently, while SHA-256 binds ingestion to the exact uploaded bytes.

THE MONEY IDEA
Separate transport authorization from repository authorization.
